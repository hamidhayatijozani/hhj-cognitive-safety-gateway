# Sbat Release Readiness

## Built
- deterministic assessment core
- cognitive risk signal
- evidence ledger with chained hashes and HMAC
- red-team scenario runner
- multi-agent evaluation
- assurance report
- Python SDK-style service layer
- CLI
- HTTP reference API
- automated tests and CI

## Required before production customer deployment
- production authentication and RBAC
- tenant isolation
- persistent database-backed ledger
- managed secret/key rotation
- API rate limiting
- observability
- security review and dependency scanning
- customer-specific policy packs
- load/performance benchmark
- deployment automation
- legal review of customer contracts and evidence-retention requirements

The repository is a functional product foundation and reference implementation. Production readiness must be established by deployment-specific verification, not by this document alone.
